# 4문 예측 카드

모든 예측은 이 네 질문으로 한다. **질문을 바꾸지 않는다** — 같은 질문을 반복해야 반사적 판별이 자동화된다.

```
① 어디서 실행되는가?
   프리렌더(빌드) / 요청시 서버 / 클라이언트

② 정적 셸에 들어가는가?
   셸에 포함 / Suspense 뒤에서 스트리밍

③ 클라이언트 번들에 포함되는가?
   O / X   — 이 파일은? 이 import는? 이 변수는?

④ 캐시된다면 lifetime은?
   cacheLife 프로필 / 무엇이 무효화하나
   (revalidateTag · updateTag · refresh 중 어느 것)
```

## 답하는 요령

**①** — `'use client'`가 위쪽 어딘가에 있는지부터 본다. 없으면 서버다. 서버라면 그다음 "이 값이 요청에 의존하는가"를 본다. 의존하지 않으면 빌드 타임에 끝난다.

**②** — 런타임 API(`cookies` / `headers` / `params` / `searchParams`)를 쓰거나 캐시되지 않은 async 읽기가 있으면 셸에 못 들어간다. `Suspense`로 감싸져 있는지 확인한다.

**③** — `'use client'` 파일에서 시작해 **import 그래프를 따라 내려간다.** 지시어가 없는 파일도 그 그래프에 있으면 번들에 들어간다.

**④** — `use cache` 유무를 보고, 있으면 어느 변종인지(기본 / `private` / `remote`) 본다. 변종에 따라 저장 위치와 공유 범위가 다르다.
