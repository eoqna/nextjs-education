# 모든 Server Action은 공개 엔드포인트다

**주차:** 2주차
**출처 오답:** 11 일차 항목에서 발생

## 흔한 오해

{role === 'admin' && <Btn/>} 같은 조건문을 사용하면 안전하다.

## 실제 동작

curl 한 줄로 뚫린다. 서버에서 제공되는 ID 값을 이용해서 바로 요청을 할 수 있다.

## 왜 그렇게 되는가

action 호출은 page를 거치지 않는다. 브라우저가 Next-Action 헤더에 ID를 실어 POST 하면,
서버가 그 ID로 함수를 찾아 직접 실행한다. page.tsx 의 검사는 이 경로에 없다.

액션에서 제공되는 ID 값은 클라이언트에서도 동일하게 값을 확인할 수 있다.

즉, ID 값이 비밀이 될 수 없다.

## 어떻게 막는가

액션 안에서 직접 조건을 추가해 접근 권한을 확인해야 한다.

## 확인 방법

페이지에 {role === 'admin' && <Btn/>} 를 추가하고 브라우저에서 개발자 도구를 통해 action id 값을 확인한다.

curl 명령어를 통해 id 값을 직접 전달하여 요청하면 조건문으로 접근을 막지 못한 것을 확인할 수 있다.
