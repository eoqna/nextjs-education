# 경계 배치 3종 — 예측표

작성: 2026-09-08 · 실행 전에 채웠다. 실행 후 `실제` 칸을 채운다.

같은 규칙에서 5회 연속 오답이 났다(오답노트 16·18·19·20일차).
설명을 여섯 번째 반복하는 대신 눈으로 확인하려고 만든 실습이다.

## ① Boom 이 안쪽 경계 안 (`/stream/nested/inside`)

```tsx
<Boundary name="바깥">
  <h1>MARKER_제목</h1>
  <Boundary name="안쪽">
    <Suspense><Boom /></Suspense>        {/* 1초 뒤 throw */}
  </Boundary>
  <Suspense><Slow sec={2} name="정상" /></Suspense>
</Boundary>
```

| 1초 뒤 | 예측 | 실제 (9/9 관측) | |
|---|---|---|---|
| 제목 | 보인다 | 보인다 | ✅ |
| 안쪽 Fallback | 안 보인다 | **보인다** | ✗ |
| 바깥 Fallback | 보인다 | **안 보인다** | ✗ |
| 정상 위젯(2초) | 안 보인다 | **보인다** | ✗ |

> 예측 안에서 충돌이 있다 — 바깥이 발동했다면서 바깥이 감싼 제목은 살아남는다고 했다.
> 이게 참이려면 Fallback 이 "터진 자리에만" 나타나야 한다. 그것이 이 실습의 쟁점이다.

## ② Boom 이 안쪽 경계 밖 (`/stream/nested/outside`)

①과 부품도 개수도 같다. Boom 과 안쪽 경계의 위치만 바뀌었다.

```tsx
<Boundary name="바깥">
  <h1>MARKER_제목</h1>
  <Boundary name="안쪽">
    <Suspense><Slow sec={2} name="정상" /></Suspense>
  </Boundary>
  <Suspense><Boom /></Suspense>          {/* 1초 뒤 throw */}
</Boundary>
```

| 1초 뒤 | 예측 | 실제 (9/9 관측) | |
|---|---|---|---|
| 제목 | 안 보인다 | 안 보인다 | ✅ |
| 안쪽 Fallback | 안 보인다 | 안 보인다 | ✅ |
| 바깥 Fallback | 보인다 | 보인다 | ✅ |
| 정상 위젯(2초) | 안 보인다 | 안 보인다 | ✅ |

## ③ catchError 경계 없음 (`/stream/nested/no-boundary`)

`Suspense` 만 남는다. 위에 있는 에러 경계는 `app/stream/error.tsx` 하나뿐이다.

| 1초 뒤 | 예측 | 실제 (9/9 관측) | |
|---|---|---|---|
| 제목 | 안 보인다 | 안 보인다 | ✅ |
| error.tsx (🅰️ 빨간 테두리) | 보인다 | 보인다 | ✅ |
| 정상 위젯(2초) | 안 보인다 | 안 보인다 | ✅ |

## 결과 — ① 1/4 · ② 4/4 · ③ 3/3

**같은 부품, 같은 개수. `Boom` 과 안쪽 경계의 상대 위치만 다른데 결과가 정반대다.**

```
①  Boom 이 안쪽 안      →  안쪽이 잡는다      →  제목 · 정상 위젯 살아남는다
②  Boom 이 안쪽 밖      →  바깥이 잡는다      →  제목 · 안쪽 · 정상 전부 사라진다
③  catchError 가 없음   →  error.tsx 가 잡는다 →  세그먼트 전체가 대체된다
```

### 예측의 내부 충돌이 관측으로 풀렸다

① 예측은 "바깥 Fallback 보인다 + 제목 보인다" 였다. 실제로는 그 조합이 없다.

```
② 가 보여준 것   바깥이 발동하면 제목도 사라진다
① 이 보여준 것   제목이 보이면 바깥은 발동하지 않은 것이다
```

"Fallback 이 터진 자리에만 나타난다" 는 그림은 화면에 존재하지 않았다.

## 규칙 (관측에서 뽑음 · 9/9)

```
① 에러는 가장 가까운 상위 "에러 경계" 에서 멈춘다.
   Suspense 는 에러 경계가 아니다 — promise 를 받지 에러를 받지 않으므로 그냥 통과한다.
   ① 에서 Boom 은 안쪽·바깥 두 경계 안에 있었지만 가까운 쪽인 안쪽만 발동했다.

② 발동한 경계가 감싼 것 전체가 Fallback 으로 대체된다.
   기준은 에러가 난 자리가 아니라 경계가 감싼 범위다.
   ② 에서 정상 위젯은 에러가 나지 않았는데도 사라졌다 — 바깥이 감싸고 있었기 때문이다.
```

세 배치가 이 두 줄로 전부 설명된다.

```
①  가장 가까운 = 안쪽    안쪽이 감싼 것만 대체    제목 · 정상 위젯 생존
②  가장 가까운 = 바깥    바깥이 감싼 것 전부 대체  전멸
③  가장 가까운 = error.tsx (경계가 그것뿐)        세그먼트 전체 대체
```
